# Brief de página: /servicios/bombas/

Página de categoría que explica todos los planes de mantenimiento de bombas.
Objetivo único: que el usuario entienda qué nivel de cobertura necesita y llame.

---

## Sección 1 — Hero

**Tipo de módulo**: Hero con texto + CTA (sin imagen de fondo grande, puede tener imagen secundaria)

```
Título (H1):       Mantenimiento de bombas de agua para edificios
Subtítulo:         Visita mensual, rotación de equipos y distintos niveles de cobertura
                   según las necesidades de tu edificio.
CTA primario:      Solicitar presupuesto  →  /contacto/
```

**Nota de diseño**: el hero no necesita ser enorme. Es una página de servicio, no una landing de marketing. Foco en claridad.

---

## Sección 2 — Qué hacemos en cada visita

**Tipo de módulo**: Texto con iconos o lista visual (2–3 columnas)

**Propósito**: establecer la base común de todos los planes antes de mostrar diferencias.

```
Título:  Cada visita mensual incluye

Items:
  🔧  Rotación de bombas
  ⚙️  Revisión de automatismos de nivel
  📋  Control general del estado del equipo
```

**Nota de contenido**: esto aplica al 100% de los planes. Es el "mínimo" que siempre está.

---

## Sección 3 — Nuestros planes

**Tipo de módulo**: Tabla comparativa o tarjetas con toggle (las tarjetas funcionan mejor en mobile)

**Propósito**: que el usuario encuentre su nivel de cobertura ideal de un vistazo.

### Opción A — Tabla comparativa (recomendada para desktop)

| | Abonado | Mantenimiento | Integral | Especial |
|---|:---:|:---:|:---:|:---:|
| Visita mensual + rotación | ✓ | ✓ | ✓ | ✓ |
| Repuestos (automáticos, térmicos, contactores, llaves TQ) | — | ✓ | ✓ | ✓ |
| Reparación de equipos | — | ✓ | ✓ | ✓ |
| Reposición de bombas | — | — | ✓ | cotizada |
| Bomba de emergencia gratuita (30 días) | — | — | — | ✓ |
| **+ Limpieza de tanques** | opcional | — | opcional | opcional |

### Opción B — Tarjetas (más visual, mejor para mobile)

```
TARJETA: Abonado
  Lo esencial
  ✓ Visita mensual
  ✓ Rotación de bombas
  ✗ Sin repuestos
  CTA: Consultar →

TARJETA: Mantenimiento
  Cobertura media
  ✓ Visita mensual
  ✓ Repuestos incluidos
  ✓ Reparación de equipos
  ✗ Sin reposición de bombas
  CTA: Consultar →

TARJETA: Integral  ← [destacado / recomendado]
  Cobertura total
  ✓ Visita mensual
  ✓ Repuestos incluidos
  ✓ Reparación de equipos
  ✓ Reposición de bombas
  CTA: Consultar →

TARJETA: Especial
  Cobertura total + emergencia
  ✓ Todo lo del Integral
  ✓ Bomba de emergencia gratuita 30 días
  ✓ Sin corte de agua durante reparaciones
  CTA: Consultar →
```

**Nota de diseño**: marcar "Integral" como el plan recomendado. Es el más vendido implícito (punto medio).

## Sección 4 — ¿Incluye limpieza de tanques?

**Tipo de módulo**: Bloque informativo simple (texto + visual)

**Propósito**: aclarar que la limpieza de tanques es un complemento que se puede agregar a cualquier plan, no un plan separado obligatorio.

```
Título:  Sumale limpieza de tanques a tu plan

Texto:   Podés incorporar la limpieza anual de tanques de agua —con análisis de
         potabilidad incluido— a cualquier plan de bombas. Disponible en frecuencia
         anual o semestral.

Opciones:
  + 1 limpieza anual de tanques
  + 2 limpiezas anuales de tanques

CTA:  Ver servicio de limpieza de tanques  →  /servicios/limpieza-de-tanques/
```

**Nota de contenido**: este bloque conecta con la página de limpieza de tanques y evita duplicar información.

---

## Sección 5 — Qué no incluye ningún plan

**Tipo de módulo**: Lista compacta, tono neutro (no negativo)

**Propósito**: gestionar expectativas antes del primer contacto. Evita llamadas con malentendidos.

```
Título:  No incluido en los planes de bombas

  ✗  Flotadores de tanques (superior e inferior)
  ✗  Cableado de ningún tipo
  ✗  Cañerías
  ✗  Accesorios

Texto pequeño:  Si necesitás estos trabajos, los cotizamos por separado.
                Ver trabajos puntuales  →  /trabajos/
```

---

## Sección 6 — ¿Cómo arrancamos?

**Tipo de módulo**: Pasos numerados (3–4 pasos, horizontal o vertical)

**Propósito**: bajar la barrera de entrada. El usuario no sabe qué plan necesita y eso lo paraliza. Mostrar que el proceso es simple.

```
Paso 1:  Nos contactás
         Por WhatsApp, teléfono o formulario.

Paso 2:  Visita técnica
         Un técnico evalúa las bombas y el estado del equipo en tu edificio.

Paso 3:  Recibís el presupuesto
         Te enviamos opciones según lo que encontramos.

Paso 4:  Arrancamos
         Coordinamos la primera visita mensual.
```

---

## Sección 7 — CTA final

**Tipo de módulo**: Banner CTA de cierre (color de fondo, texto centrado)

```
Título:  ¿No sabés qué plan necesita tu edificio?
Texto:   Contactanos y un técnico hace la evaluación sin compromiso.
CTA:     Hablar con un técnico  →  /contacto/
```
