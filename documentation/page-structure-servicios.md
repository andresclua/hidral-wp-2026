# Hidral — Estructura de contenido: páginas de servicios

Cada página de categoría sigue la misma lógica: explicar qué es, qué incluye, gestionar expectativas y llevar al contacto. Las variaciones son de contenido, no de estructura.

---

## Estructura base (aplica a las 4 páginas)

```
1. Hero
2. Descripción del servicio
3. Qué incluye / Planes disponibles
4. Qué NO incluye (gestión de expectativas)
5. ¿Para quién es?
6. CTA de contacto
```

---

## /servicios/bombas/

**Objetivo**: que el usuario entienda que hay distintos niveles de cobertura y elija llamar para cotizar el que le conviene.

```
HERO
  Título: Mantenimiento de bombas de agua
  Bajada: visita mensual, rotación de equipos, distintos niveles de cobertura según necesidad
  CTA: Solicitar presupuesto

DESCRIPCIÓN
  Qué hace Hidral en cada visita mensual (rotación de bombas, revisión de automatismos)
  
PLANES (tarjetas o tabla comparativa)
  Abonado         → visita mensual, sin repuestos
  Mantenimiento   → visita mensual + repuestos (automáticos, térmicos, contactores, llaves TQ) + reparación
  Integral        → todo lo anterior + reposición de equipos (bombas)
  Especial        → como Integral pero con bomba de emergencia gratuita 30 días si hay retiro

QUÉ NO INCLUYE (en todos los planes)
  Flotadores de tanques / Cableado / Cañerías / Accesorios
  (Esto evita llamadas con expectativas incorrectas)

¿PARA QUIÉN ES?
  Edificios residenciales, condominios, edificios de oficinas
  Administradores de propiedades

CTA
  "¿No sabés qué plan te corresponde? Contactanos y un técnico evalúa tu edificio"
  → Botón a /contacto/
```

## /servicios/sanitaria/

**Objetivo**: transmitir que el servicio es 100% personalizado según las instalaciones del edificio, no hay un precio fijo — hay que llamar.

```
HERO
  Título: Servicio sanitario para edificios
  Bajada: mantenimiento mensual de instalaciones sanitarias, cotización según edificio
  CTA: Consultar servicio

DESCRIPCIÓN
  Qué abarca la sanitaria de un edificio (graseras, cámaras, cañerías de desagüe)
  Por qué requiere evaluación técnica previa

QUÉ PUEDE INCLUIR (listado visual, no como "plan" sino como "tareas posibles")
  ✓ Graseras colectivas e individuales
  ✓ Hidrolavado
  ✓ Pasaje de desobstructora
  ✓ Limpieza de cámaras
  ✓ Resumideros de apartamentos
  (El técnico define cuáles aplican según el edificio)

CÓMO FUNCIONA EL PROCESO
  1. Contacto inicial
  2. Visita técnica al edificio
  3. Cotización personalizada
  4. Inicio del servicio mensual

¿PARA QUIÉN ES?
  Edificios con instalaciones de desagüe colectivas
  Administradores que necesitan mantenimiento preventivo

CTA
  "Cada edificio es diferente. Contactanos para una evaluación sin compromiso"
  → Botón a /contacto/
```

## /servicios/limpieza-de-tanques/

**Objetivo**: explicar el proceso y el valor del análisis de potabilidad incluido. Es el servicio más "tangible" y entendible para el usuario final.

```
HERO
  Título: Limpieza de tanques de agua potable
  Bajada: limpieza profesional con análisis de potabilidad incluido, 1 o 2 veces al año
  CTA: Solicitar limpieza

DESCRIPCIÓN
  Por qué es importante limpiar los tanques (salud, normativa, calidad del agua)
  Qué incluye: limpieza + análisis de potabilidad

MODALIDADES
  1 limpieza anual   → estándar
  2 limpiezas anuales → para edificios con mayor demanda o exigencia normativa

CÓMO ES EL PROCESO
  1. Coordinación de fecha con la administración
  2. Limpieza profesional del tanque
  3. Análisis de potabilidad del agua
  4. Informe/certificado del análisis

¿SE PUEDE CONTRATAR SOLO?
  Sí. La limpieza de tanques es un servicio independiente.
  También se puede incluir dentro de un abono de bombas o sanitaria.

CTA
  "Coordiná la limpieza de tu edificio"
  → Botón a /contacto/
```

## /servicios/contraincendio/

**Objetivo**: posicionarse como servicio especializado y confiable. Es el servicio más regulado y el usuario busca tranquilidad, no precio.

```
HERO
  Título: Mantenimiento de equipos contra incendio
  Bajada: control mensual de presión y caudal, prueba anual por nicho
  CTA: Consultar abono

DESCRIPCIÓN
  Qué implica tener equipos contra incendio en regla
  Por qué el mantenimiento mensual es obligatorio

QUÉ INCLUYE
  ✓ Control mensual de presión y caudal de arranque/parada del grupo contraincendios
  ✓ Prueba anual de caudal en cada nicho

FRECUENCIA Y COBERTURA
  Visita mensual al área de instalación
  Una prueba por nicho al año

¿PARA QUIÉN ES?
  Edificios residenciales y comerciales con grupo contraincendios instalado
  Administradores que necesitan acreditar mantenimiento ante organismos

CTA
  "Mantené tus equipos en regla. Hablá con nosotros"
  → Botón a /contacto/
```

## Nota para el cliente

Los módulos marcados como "tarjetas comparativas" o "listado visual" son los que más impacto visual tienen y vale la pena trabajarlos bien en diseño. Los CTAs al final de cada página siempre van a `/contacto/` — la web no cierra ventas, abre conversaciones.
